# 올팍 주차예보 (배포본)

올림픽공원 공연 일정과 실시간 주차대수로, 공연날 **입차가 몰리는 때**와 **공연 뒤 출차가 몰리는 때**를 알려 주는 정적 웹 서비스의 배포본입니다.

- 한국체육산업개발(주)가 개방한 공공데이터를 활용한 개인 개발 작품이며, **기관의 공식 서비스가 아닙니다.** 실제 주차 상황은 현장 안내를 따르세요.
- 서버 없이 동작합니다(index.html + assets/ + data/*.json). 회원가입·쿠키·위치 수집이 없습니다.
- 실시간 주차 대수는 브라우저가 기관 누리집 공공데이터 개방목록에 공개된 실시간 주차현황 API를 직접 호출해 표시합니다.

## 사용 데이터 (한국체육산업개발(주), 공공데이터포털 번호)
| 번호 | 데이터 |
|---|---|
| 15138735 | 올림픽공원 입출차 정보(2024-07) |
| 15164156 | 주차장 혼잡도 정보(2025-02~2026-08) |
| 15131671 | 월별주차현황(2023~2025) |
| 3037877 | 올림픽공원 공연정보(기관 누리집 공연 일정) |
| 15168686 | 실시간 주차현황 |

이 저장소에는 화면에 필요한 파일만 있습니다. 코드는 MIT 라이선스이고, 데이터는 각 데이터의 이용허락 조건을 따릅니다.
